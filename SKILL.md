# agentic-identity

People, agents, and the access they share: sign-in, delegation, invites, links, and an audit trail.

Release 0.1.0 is a preview. It has principals and delegation chains, the sharing
model (roles, invites, links, audit), six ports, memory and Cloudflare (D1, R2)
adapters, and contract suites. It has no SDK, CLI, MCP server, or HTTP API yet.
Read `README.md` for the current status before you use it.
